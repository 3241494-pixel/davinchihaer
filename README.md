# Da Vinchi Hair

Next.js, static export (`output: "export"`), деплой на Cloudflare Pages.

## Разработка

```bash
npm run dev
```

## Сборка и предпросмотр

```bash
npm run build    # next build -> папка out/
npm run preview  # npx serve out
```

## Cloudflare Pages

Build command: `npm run build`. Output directory: `out`.
